## 📖 소개

**미니법정**은 당신이 형사법원의 판사가 되어, 검사의 공소사실과 변호인의 반박을 듣고
직접 형량을 정하는 브라우저 기반 미니게임입니다.

- 무고한 사람에게 유죄를 선고하거나, 죄질에 맞지 않는 터무니없는 판결을 내리면
  **"법왜곡죄"**로 당신이 고소당하는 배드 엔딩을 맞이합니다.
- 반대로 죄를 지은 사람을 함부로 풀어주면 **시민의심**이 쌓여, 결국 판사직에서
  물러나야 하는 엔딩도 있습니다.
- 실제 형법 조항(절도죄, 살인죄, 사기죄, 상해치사죄 등)을 참고해 만든 "법률 카드"를
  판결 직전에 확인할 수 있습니다.

## ✨ 주요 기능

| 카테고리 | 내용 |
|---|---|
| 🎭 캐릭터 | 도트 스타일로 직접 그린 검사(법복)·변호인(정장)·피고인(수의) 픽셀 스프라이트, 상황별 표정 변화 |
| ⚖️ 판결 시스템 | 선고유예 / 벌금 / 집행유예 / 징역(연수 직접 입력) / 무기징역 / 사형 / 무죄 중 선택 |
| 📚 법률 카드 | 사건별 실제 형법 조항 + 작량감경 설명 + 유사 판례 참고 문구 |
| 🎚️ 난이도 | 초심자 / 보통 / 실전 3단계 (판정 기준의 관대함이 달라짐) |
| 🕹️ 게임 모드 | 정식 재판(순서대로) / 랜덤 재판 / 사건 선택(연습 모드) / 튜토리얼 |
| 🎪 코믹 사건 | "공공장소 자칭 공주 소동" 등, 사실은 죄가 안 되는 걸 알아채고 무죄를 내려야 하는 사건 포함 |
| 👥 국민참여재판 | 배심원 평결(권고적 효력)을 확인한 뒤 최종 판결 — 배심원과 다른 판결을 내리면 여론이 갈림 |
| 🔊 사운드 | Web Audio API로 만든 대사 블립음, 상황별 BGM(평시/선고/코믹/중대사건), 방청객 반응음(환호/야유/탄식/박수) |
| 🔍 보조 기능 | 증거물 열람, 공방 전체 요약보기, 여론 게이지, 재범 콜백, 랜덤 돌발 이벤트 |
| 🏅 기록/성장 | 재판 기록·업적 영구 저장(브라우저 저장소), 판사 성향 분석(원칙주의형/온정주의형/균형형), 결과 공유 카드, 판결문 다운로드 |
| 🌐 접근성 | 텍스트 속도/글자 크기/양형 힌트 조절, 한국어·영어 메뉴 지원 |

## 🛠️ 기술 스택

- **Vanilla HTML / CSS / JavaScript** (단일 파일, `mini-court.html`)
- Canvas 2D API — 픽셀 스프라이트 렌더링
- Web Audio API — 배경음악·효과음 전부 코드로 직접 생성 (외부 음원 파일 없음)
- `window.storage` — 재판 기록·업적·설정 영구 저장

> 별도의 빌드 과정이나 서버가 필요 없습니다. `mini-court.html` 파일 하나만 있으면
> 브라우저에서 바로 실행됩니다.

## 🚀 실행 방법

### 로컬에서 실행
```bash
git clone https://github.com/ChoeHanMin/mini-court.git
cd mini-court
# 그냥 브라우저로 mini-court.html을 열면 됩니다.
```

### GitHub Pages로 배포된 버전
저장소 Settings → Pages에서 배포 후 아래 형식의 링크로 접속:
```
https://ChoeHanMin.github.io/mini-court/mini-court.html
```

## 🙋 왜 만들었나요

법정 드라마를 보면서 "내가 판사라면 어떤 형을 내릴까"라는 질문에서 출발한 프로젝트입니다.
단순한 권선징악이 아니라, **판사에게도 '적정한 판단'이라는 책임이 있다**는 걸 게임 메커니즘으로
표현해보고 싶었습니다 (지나치게 관대해도, 지나치게 가혹해도 대가가 따르는 구조).
